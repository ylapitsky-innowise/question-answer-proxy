
Структура папок для конфигурации чувствительных данных

```yaml
# Рекомендуемая структура
project/
├── src/
│   └── main/
│       └── resources/
│           └── config/
│               └── sources.example.yaml   # Только пример-шаблон (в репозитории)
├── target/                               # Папка со скомпилированным JAR (не в Git)
│   └── question-answer-proxy.jar
├── config/                               # ВНЕШНЯЯ папка (НЕ В JAR!)
│   └── sources.yaml                      # Реальный файл с данными (НЕ В РЕПОЗИТОРИИ)
└── .gitignore                            # Добавляем config/sources.yaml
```
## 📁 Как организовать структуру
1. Для локальной разработки (IDEA)
   Создайте папку config в корне проекта (на одном уровне с src и pom.xml):

#### Создаем структуру `config/sources.yaml`

2. Для деплоя на Render
   На Render файлы можно загрузить через Secret Files или просто добавить через GitHub (если файл без секретов). Но в вашем случае лучше всего:

### Вариант A: Через Render Environment Variables (рекомендую)

Просто хранить конфиг как переменную окружения. В `application.yaml` укажите:
```yaml
sources:
  config-json: ${SOURCES_CONFIG_JSON:null}
```

А в _Render_ добавить `SOURCES_CONFIG_JSON` как _JSON_-строку.

### Вариант B: Через загрузку файла на сервер
```bash
# При деплое скопировать файл на сервер
scp config/sources.yaml user@server:/app/config/
```




| Файл                  | Местоположение             | В репозитории? | Попадает в JAR? | Для чего        |
|:----------------------|:---------------------------|:---------------|:----------------|:----------------|
| sources.example.yaml	 | src/main/resources/config/ | ✅ Да	          | ✅ Да	           | Шаблон, пример  |
| sources.yaml	         | ./config/ (рядом с JAR)	   | ❌ Нет	         | ❌ Нет	          | Реальный конфиг |

> Важно: Папка config — это внешняя папка, созданная вручную на сервере или локально. Она лежит вне JAR, что позволяет:
> ✅ Редактировать без пересборки   
> ✅ Хранить секреты вне репозитория   
> ✅ Настраивать под каждого пользователя
