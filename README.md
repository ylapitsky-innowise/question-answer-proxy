# Деплой (Deployment):

**Deployment (Деплой)** или **Continuous Deployment (CD)** из данного GitHub-репозитория происходит через [Render.com](https://render.com/) [(Ссылка на страницу входа)](https://dashboard.render.com/login-next?next=%2Fweb%2F).

---
## ⚙️ Как это работает
Настроен процесс **Continuous Deployment (CD)**. При пуше в ветку `main` облачная платформа Render через вебхуки GitHub автоматически собирает и разворачивает приложение.

> 💡 Детали процесса:
> Для деплоя я использовал Render как **PaaS-решение**.
> Схема работы такая:
> 1. Я пушу код в GitHub.
> 2. GitHub отправляет вебхук на Render.
> 3. Render подхватывает изменения, собирает артефакт (через Maven) и запускает контейнер.
> По сути, это настроенный Continuous Deployment, который избавляет от ручной сборки и доставки кода на сервер.
